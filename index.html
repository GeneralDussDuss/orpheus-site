01 // THE PLAYER

A TUI on the Outside

That is not a video and not a CSS trick. It is Prism — Orpheus's own fragment shader, compiled to WebGL and running in your browser.

Change the pace and watch what happens. The bars do not just get taller; the world arrives sooner. A faster track moves the camera further every second.

Orpheus streams hi-res from TIDAL and hands 32 bands of live spectrum to a shader sitting inside the same window. The player, the stage, the desktop widget and the bar spectrum are one engine at four sizes — four surfaces, and nothing that springs out of a control.

03 // ROADMAP

Where This Is Going

Orpheus has been built in the open on one machine for two weeks. Here is what already works, what is on the bench right now, and what is queued behind it.

Shipped

The player

v0.1

Hi-res TIDAL streaming through mpv, MPRIS so the rest of the desktop can see the track, favourites everywhere, and a queue that survives a service restart.

Shipped

One engine, four surfaces

v0.1

Seven fragment shaders behind five visual styles, feeding the player rail, the fullscreen stage, the desktop widget and a bar spectrum — with no popout menus and nothing that springs out of a control.

Shipped

Pace, not loudness

v0.1

The world travels at the tempo of the track instead of flinching at its volume. Tempo comes from autocorrelating the spectral-flux envelope, and the shaders read an integrated travel distance rather than the clock.

In progress

Source release

Now

GPL-3.0-or-later, the whole thing: the Python daemon, the QML plugin and every shader. Quickshell and tidalapi are already LGPL-3, so it sits on the stack without friction.

In progress

An install path a stranger can follow

Next release

Right now installing means knowing where the daemon, the user unit, the plugin symlink and the shader build each go. That becomes one documented sequence, then one command.

Queued

The stage, finished

Soon

The player window got the full TUI treatment; the fullscreen stage and the mini-player have not. Same box-drawing chrome, same restraint — and fresh captures at the quality the shaders actually deserve.

Queued

Runs on a machine that isn't mine

Soon

Multi-monitor placement, theme coverage beyond the 29 already handled, and the rough edges that only show up on hardware I do not own. Issues welcome once the source is up.

Not planned

Other providers

—

TIDAL stays the only backend, deliberately. Spotify cannot legally stream to a third-party client at all, and carrying a provider abstraction for one provider costs more than it returns.

04 // GET IT

Run It Yourself

Orpheus is a Quickshell plugin plus a small Python daemon. There is no installer yet — that is the next thing on the list — but the path is short.

You need a TIDAL subscription for playback; the hi-res tier needs the PKCE sign-in, which the player walks you through. Nothing is downloaded and nothing is decrypted: it streams, the same as the official client.

Omarchy / HyprlandQuickshellPython 3.13+ mpvuvTIDAL account
This page profiled your device as … and picked its render resolution to match.
bash 
# the daemon and its unit
$ git clone https://github.com/GeneralDussDuss/orpheus
$ cd orpheus && uv sync
$ cp orpheusd.service ~/.config/systemd/user/
$ systemctl --user enable --now orpheusd

# the shell plugin
$ ln -s "$PWD" ~/.config/omarchy/plugins/orpheus
$ omarchy restart shell

# Super+Shift+M opens the player
